# Portfolio site

Plain HTML/CSS. No build step.

- `index.html` – the main "spec" page
- `projects/example-app.html` – case study template. Copy it per project and rename it (e.g. `projects/my-app.html`); links work as `/projects/my-app`
- `styles.css` – all styling
- `assets/` – put `resume.pdf` and images here

Preview locally: open `index.html` in a browser, or run `npx serve .` and visit http://localhost:3000

Deploy: push to GitHub. Vercel redeploys automatically.
